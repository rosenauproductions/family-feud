      How the question bank works

      Make a pack

      • By hand: click + New pack, type a name, then add questions and answers.
      • With AI: click ✨ AI prompt, describe the theme, copy the prompt into any AI, then paste its reply into Import from AI.
      • Edit an existing pack: click it in the list on the left.

      Rules the game expects

      • Up to 8 answers per question (the board has 8 slots). 4–8 plays best.
      • Points are how many of 100 surveyed people said it: whole numbers, highest first, adding up to 100.
      • Use Sort and Make it 100 on a question to fix order and totals in one click.
      • Join synonyms with " / " (e.g. TV / TELEVISION). The board shows answers in CAPS automatically.
      • Red issues block saving. Yellow ones are suggestions.

      Saving

      • Save to game writes the pack into the game's question folder. On the host controller, reopen setup (or refresh) and pick it from the pack list.
      • Download .json saves a copy to your computer. For the cloud (Render) version, add downloaded files to data/questions/ in the GitHub repo. Saving there is turned off.
      • Your work-in-progress is kept in this browser, so a refresh won't lose it.
